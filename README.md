# Проєкт: Пошук фільмів та мультфільмів (Project3_movies)

Цей проєкт — це React-додаток для зручного пошуку фільмів та мультфільмів, перегляду детальної інформації про них, списку акторів та відгуків користувачів. 

## 🚀 Жива сторінка проєкту (Live Page)

Повноцінну робочу версію додатка можна переглянути в інтернеті за посиланням:
👉 [project3_movies](https://lenakopa3007-bit.github.io/project3_movies/)

---

## 🛠️ Технологічний стек

* **Фреймворк**: React 18
* **Маршрутизація**: React Router DOM (v6)
* **Стилізація**: Emotion / Styled Components
* **Інтеграція з API**: TMDB API (The Movie Database)
